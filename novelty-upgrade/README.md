# Novelty Upgrade — VeriSciRec

Complete, self-contained implementation of nine technical extensions to the core
VeriSciRec pipeline (learned verifier, relation experts, conformal calibration,
heterogeneous graph, counterfactual tests, hard negatives, agentic verifier, rationale
revision, DPO), built in this folder rather than patched into the original `notebooks/`.

This folder **reads** source data from the existing project (`../data`, `../benchmarks`,
`../embeddings`) but never writes back to it. Everything new — code, caches, trained
models, results — lives here.

## Why a new folder

The original `notebooks/01`–`10` and `benchmarks/final/` already contain real, validated
work: the 10,000-instance SciRecBench corpus, the 68/303 expert-annotated gold set
(κ=0.80), the rule-based SciRecTrace verifier with real head-to-head numbers, and a
working multi-agent recommendation pipeline. None of that is being redone. What's new
here is the technical upgrade itself — a learned verifier, calibration, a heterogeneous
graph, real agentic behavior, and finishing the DPO/rationale-revision work that was
already partially scaffolded.

## Compute model

Everything except item 9 (DPO training) is CPU-feasible, but **all experiments are run
on Kaggle** for a single consistent environment.
Every notebook below is generated by a `build_*.py` script in `src/` that assembles the
notebook JSON and `ast.parse`-compile-checks every code cell (a broken cell fails loudly
at generation time, not silently on Kaggle) — that compile-check is the only "execution"
that happens off Kaggle. All real runs against real data happen on Kaggle; the numbers
recorded in `outputs/*.json` are from earlier local runs and are kept as reference points,
not as a substitute for the Kaggle runs.

## Status

Every notebook is generated from already-syntax-validated `src/` modules and
compile-checked (`ast.parse`) at generation time, then run on Kaggle — not executed
against real data locally. Nothing gets written into the manuscript until a notebook has actually
run on Kaggle and produced the number being cited.
