# Data

GitHub rejects files over 100 MB, so the large data files are **not stored in git**. This
page lists every data file the code expects, where it comes from, and where to put it.

## 1. Included in the repository

| Path | Contents |
|---|---|
| `scirecbench_human_verified_subset.jsonl` (repo root) | **Expert-gold subset**: 68 instances, 303 claims |
| `benchmarks/final/nb2-output/scireqa_human_verified_subset.jsonl` | The same gold subset under the filename the notebooks read |
| `benchmarks/final/nb2-output/iaa_summary.json` | Inter-annotator agreement (mean Cohen's κ = 0.80, Krippendorff's α = 0.80) |
| `benchmarks/final/nb2-output/table5_human_validation.csv`, `minicheck_calibration.json` | Human-validation and calibration results |
| `benchmarks/final/human_eval/` | Annotation sheets, three annotators' completed labels, sample IDs |
| `benchmarks/final/relational/citecheck_results*.json` | VeriSciRec (CiteCheck) verdicts |
| `notebooks/outputs/`, `notebooks/nb07-outputs/`, `outputs/` | Small result files and figures |
| `novelty-upgrade/outputs/*.json`, `fusion_mlp.pt` | Extension-experiment results and the small fusion model |

## 2. GitHub Release assets (SciRecBench v1.1)

Download from the repository's **Releases** page, decompress (`gunzip *.gz`), and put
each file at the path shown.

| Release file | Size (raw) | Put it at |
|---|---|---|
| `scireqa_full_relational_v1.1_humanmerged.jsonl.gz` | 125 MB | `benchmarks/final/nb2-output/` |
| `scireqa_arxiv_relational_v1.1.jsonl.gz` | 80 MB | `benchmarks/final/relational/` |
| `scireqa_acl_relational_v1.1.jsonl.gz` | 23 MB | `benchmarks/final/relational/` |
| `scireqa_pubmed_relational_v1.1.jsonl.gz` | 22 MB | `benchmarks/final/relational/` |
| `scireqa_full_v1.1.FINAL.jsonl.gz` | 117 MB | `benchmarks/final/after_diagnosis/` |
| `scireqa_full_with_negatives_v1.1.FINAL.jsonl.gz` | 154 MB | `benchmarks/final/after_diagnosis/` |
| `scireqa_hallucination_eval_v1.1.FINAL.jsonl.gz` | 38 MB | `benchmarks/final/after_diagnosis/` |
| `citecheck_refs_cache.json.gz` | 42 MB | `benchmarks/final/relational/` (cached Semantic Scholar citation edges) |
| `rationales_checkpoint_relational_v1_1.json.gz` | 12 MB | `benchmarks/final/relational/` (generated rationales) |

`SHA256SUMS.txt` in the release lists checksums. Maintainers rebuild these assets with
`bash scripts/make_release.sh`.

The canonical benchmark file is `scireqa_full_relational_v1.1_humanmerged.jsonl`. Its
schema is documented in [`benchmarks/final/README.md`](benchmarks/final/README.md).

## 3. Source corpus and embeddings (needed only to rebuild the benchmark or run retrieval)

These files go in `data/` and `embeddings/`, which `notebooks/config.py` resolves
relative to the repository root. On Kaggle, attach them as a dataset (default slug
`maper-data`; see `config.py`).

| Path | Size | Description |
|---|---|---|
| `data/papers_metadata.csv` | 312 MB | Canonical arXiv corpus: 239,618 papers (`arxiv_id, title, abstract, authors, published, categories, pdf_url`) |
| `data/rated_papers.csv` | 34 MB | Explicit user ratings (`arxiv_id, user_id, rating, time`), 774,092 rows |
| `data/implicit_interactions.csv` | 24 MB | Implicit interactions (`arxiv_id, user_id, time`) |
| `data/abstract_sentences.csv` | 3 MB | Sentence-split abstracts |
| `data/paper_metadata.json` | 323 MB | Extended paper metadata |
| `embeddings/paper_embeddings_full.npy` | 937 MB | 1024-d paper embeddings (benchmark hard negatives / difficulty) |
| `embeddings/paper_embeddings_256d.npy` | 235 MB | 256-d reduced embeddings |
| `embeddings/faiss_index.bin` | 240 MB | FAISS index over the embeddings |
| `embeddings/paper_id_mapping.json` | 5 MB | `arxiv_id → row` mapping |
